Falta configurar el ID de cliente de Google.

Cómo funciona

Google Sheets almacena pacientes, consultas, pagos y el índice de archivos.

Google Drive almacena imágenes, PDFs y documentos en una carpeta separada por paciente.

Los datos clínicos no se guardan dentro de GitHub ni dentro del código de la aplicación.
